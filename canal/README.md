# canal de actualización

Piezas de actualización de una herramienta personal hecha en Excel con macros, compartida con un
grupo pequeño de compañeros de trabajo. Son código y plantillas de documentos, comprimidos y
ofuscados: la clave viaja en el propio módulo que actualiza, así que esto no protege nada, solo
evita el vistazo casual.

Aquí no hay datos personales ni información de ningún caso de trabajo. Dos verificadores lo
comprueban antes de escribir cada pieza y abortan si encuentran algo.

`update.txt` es el manifiesto: por pieza, su archivo y el sha256 de su contenido. El libro lo
descarga primero y baja solo las piezas que no tenga ya.
